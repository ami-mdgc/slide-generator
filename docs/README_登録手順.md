# slide-generator スキル｜登録手順と使い方

月次総会の生データ（Googleスプレッドシート）を、事業ごとの月次総会用Markdownに自動で清書・変換するスキルです。

---

## できること

月次総会シートのリンクを貼るだけで、5事業（みんなの買取／不用品回収の窓口／おそうじ合衆国／gaiheki+／解体相談所）ぶんのMarkdownを、決まったフォーマットで一括生成します。担当者が書いた走り書きの下書きも、言い切り文体に清書したうえで整形します。

---

## 登録手順

1. `SKILL.md` を用意する（このフォルダに同梱）。
2. Claude の設定からスキルとして登録する（Capabilities → Skills → アップロード）。
3. 登録後、チャットで月次総会シートのリンクを貼るか「月次総会のMD作って」と依頼すると自動で起動します。

---

## 使い方

チャットに月次総会シートのリンクを貼り、こう言うだけです。

> このシートから月次総会のMarkdownを作って

- 事業を指定しなければ、D〜H列の全事業を順に出力します。
- 「みんなの買取だけ」のように指定すれば、その事業だけ出します。

---

## 動かすための前提（重要）

うまく動かないときは、たいてい以下のどれかです。

1. **Google系コネクタが有効になっていること**
   素のスプレッドシートURL（docs.google.com/spreadsheets/...）は、コネクタ無しでは読めません。チャットで Google Workspace か Google Drive のコネクタを接続してください。

2. **シートの閲覧権限があること**
   コネクタはあなたのアカウント権限で読みます。対象シートが自分に共有されているか確認してください。

3. **対象タブが生データのタブであること**
   複数タブがある場合は、各事業の生データが入った月次総会タブ（例「2026年5月」）を対象にします。リンクの末尾の `gid` でタブが変わるので、生データタブを開いた状態のURLを貼ると確実です。

---

## 生成後にやること

清書する都合上、AIが数字や固有名詞に触れてしまう可能性がゼロではありません。**金額・割合・日付・社名（エンパワー様、バイセル様など）は、元シートと突き合わせて目視チェック**してください。ver1は人の最終確認込みの運用です。
