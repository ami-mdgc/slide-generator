# 営業資料スライド生成システム

デザインリテラシーのない営業マンでも、マークダウンファイルから美しいプレゼンテーションスライドを簡単に作成できるWebアプリケーションです。

## 主な機能

### 📄 マークダウンからスライド生成
- `.md`または`.txt`ファイルをアップロードするだけ
- `---`でスライドを自動分割
- 見出し、箇条書き、強調表示などに対応

### 🎨 テンプレートシステム
- **スライドタイプ指定**で自動的にデザインテンプレートを適用
- 月次総会、四半期報告など、目的別のテンプレートセット
- Figmaで作成したプロフェッショナルなデザイン

### 🎨 カスタマイズ可能なデザインシステム
- **Figma連携**: Figmaで作成したデザインシステムを自動同期
- 4つのプリセット（コーポレート、モダン、クリエイティブ、ミニマル）
- カスタムカラーパレット設定
- レイアウト調整（配置、余白）
- 設定は自動保存され、次回も引き継がれます

### 🤖 AI修正アシスタント
自然言語でスライドを簡単に修正できます：
- 「タイトルを大きくして」
- 「箇条書きを3つに減らして」
- 「『重要』を太字にして」

### 🖥️ プレゼンテーション機能
- キーボードショートカット対応（矢印キー: 前後移動、F: フルスクリーン）
- スライド一覧表示
- ページ番号表示

### 💾 エクスポート機能
編集後のスライドをマークダウンファイルとしてダウンロード可能

## 使い方

### 1. ファイルをアップロード
サンプルファイルを使って試すことができます：
- `sample-presentation.md` - 基本的なプレゼンテーション
- `sample-monthly-meeting.md` - 月次総会用テンプレート（推奨）

### 2. スライドを確認
- 左側：スライド一覧（クリックで移動）
- 中央：スライド表示
- 右側：AI修正アシスタント

### 3. AIで修正
チャット欄に修正内容を入力：
```
例：
- タイトルを目立たせて
- 箇条書きを3つに減らして
- 「重要」を太字にして
```

### 4. Figma連携（オプション）

#### 方法A: JSONインポート（推奨）

1. 右上の「JSONインポート」ボタンをクリック
2. Figmaで設定したカラーバリアブルをJSON形式で貼り付け
3. 「インポート」をクリック

**JSON形式の例:**
```json
{
  "colors": {
    "primary": "#1e40af",
    "secondary": "#64748b",
    "background": "#ffffff",
    "text": "#1e293b",
    "accent": "#3b82f6"
  }
}
```

#### 方法B: Figma API連携（CORS制限あり）

**注意:** ブラウザからの直接アクセスにはCORS制限があります。詳細は `FIGMA_WORKAROUND.md` を参照してください。

1. 右上の「Figma連携」ボタンをクリック
2. FigmaファイルのURLを入力
3. Personal Access Tokenを入力
   - **重要:** トークン作成時に「**File variables**」スコープを選択してください
   - 「File content」スコープも推奨
4. 「同期開始」をクリック（環境によっては動作しない可能性があります）

### 5. デザイン設定
右上の「デザイン設定」ボタンで会社のブランドに合わせたカラーやレイアウトを設定：

**プリセット:**
- コーポレート: ビジネス向けの落ち着いたブルー基調
- モダン: 洗練されたダークグレー基調
- クリエイティブ: 創造的なパープル基調
- ミニマル: シンプルなモノクローム

**カスタム設定:**
- プライマリーカラー、セカンダリーカラー、背景色、テキストカラー、アクセントカラーを自由に設定
- タイトル配置（左揃え、中央揃え、右揃え）
- 余白サイズ（コンパクト、標準、広め）

### 6. エクスポート
右上の「エクスポート」ボタンで修正後のマークダウンをダウンロード

## テンプレートシステムの使い方

### スライドタイプの指定

マークダウンの**最初に**フロントマターを追加：

```markdown
---
slideType: 月次総会
date: 2026年4月
---

# 先月の振り返り（2026年4月実績）
...
```

### 利用可能なスライドタイプ

#### 月次総会
5つのスライドテンプレートが自動適用されます：
1. **先月の振り返り** - 実績サマリーと数値指標
2. **変動要因** - 前月比の変化要因分析
3. **今月のテーマと目標** - 当月の方針と目標
4. **今月の施策** - 具体的なアクションプラン
5. **特記事項** - その他の重要な情報

詳細は `sample-monthly-meeting.md` を参照してください。

## マークダウンの書き方

### スライドの区切り
```markdown
# 最初のスライド

内容...

---

# 2番目のスライド

内容...
```

### 見出し
```markdown
# 大見出し
## 中見出し
### 小見出し
```

### 箇条書き
```markdown
- 項目1
- 項目2
- 項目3
```

### 強調
```markdown
**太字**
*イタリック*
```

## キーボードショートカット

- `→` : 次のスライド
- `←` : 前のスライド
- `F` : フルスクリーン切り替え
